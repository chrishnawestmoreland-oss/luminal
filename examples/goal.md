# Example goal

Try Luminal with this goal (no API key needed):

```bash
npm start -- "Read this file and write a one-paragraph summary of Luminal to SUMMARY.md"
```

A harder one, with a model key set:

```bash
npm start -- "Research three open-source autonomous agents, compare them on safety, tool use and ease of setup, and save the comparison to AGENTS_COMPARED.md"
```
